
# Validador de edad


## Introduccion
Este es un proyecto simple de **HTML**, **CSS** y **JavaScript** que solicita al usuario su nombre y edad, valida la información y muestra un mensaje personalizado. También guarda el historial en una tabla visible en la página.

##Tecnologias
* HTML
* CSS
* JavaScript

### Funcionalidades
- Validación de nombre y edad
- Mensajes personalizados según edad
- Tabla de historial en la misma página

### Como usar
1. Clona o descarga este repositorio.
2. Abre el script **index.html** o puedes dirigirte al link https://robertoagomez99.github.io/validador_edad/
3. Puedes ingresar tu nombre y edad
